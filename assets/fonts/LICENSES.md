# Font licenses

UIRPG ships only fonts and (later) audio. All three font families are open-licensed.

| Family | Files | Source | License |
|---|---|---|---|
| **Spectral** | `Spectral-Regular.ttf`, `Spectral-SemiBold.ttf` | [Google Fonts — Spectral](https://github.com/google/fonts/tree/main/ofl/spectral) | SIL Open Font License 1.1 (see `OFL.txt`) |
| **Inter** | `Inter-Variable.ttf` | [Google Fonts — Inter](https://github.com/google/fonts/tree/main/ofl/inter) | SIL Open Font License 1.1 |
| **IBM Plex Mono** | `IBMPlexMono-Regular.ttf`, `IBMPlexMono-Medium.ttf` | [Google Fonts — IBM Plex Mono](https://github.com/google/fonts/tree/main/ofl/ibmplexmono) | SIL Open Font License 1.1 |

`OFL.txt` is the license text as distributed with Spectral. The Inter and IBM Plex Mono
families are distributed under the same SIL Open Font License 1.1; their upstream
repositories contain the corresponding copyright notices.

These files are the only binary assets in the project. Screenshots under
`screenshots/` are CI artifacts excluded from the build with `.gdignore`.
