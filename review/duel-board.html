01 / THE RULE

The table was cheating the card.

The old Duel Board used 165px board cards, 96px hand cards, and 64px set-card peeks. That is three card sizes in one duel. The variants below use one size per board — all 5:7, all with the same name/type/rules/stats anatomy.

HAND = BOARD

The card in your hand is the same object as the card on the mat. It can be played without changing size.

SPELL / TRAP = MONSTER

The backrow is a real row of full cards. A set card is a face-down card, not a stamp.

ALL LANES VISIBLE

No tabs, no focus lane, no hidden row. The square window shows the entire board.

02 / FOUR BOARDS

Same square. Four card budgets.

The size difference is the trade: every board shows all six zones per side and all five hand cards, but the card size changes with how much overlap the layout uses.

All frames are 900 × 900 actual pixels. The card size stated on each frame is the size of every card in that board.

What changes

  • Every spell/trap slot is a full card back at the same size as the monster.
  • Every hand card is the same size as the board card.
  • Four complete rows survive inside 900px by using a 105px card.

Effect language

Damage on the card, target bracket, score rail. No peeks, no shrunken hand.

Tradeoff

105px is the smallest card in the set, but it is the only size where all 12 board cards and five hand cards are fully visible.

What changes

  • The spell/trap card is a full 145px card, tucked behind the 145px monster.
  • That overlap buys the biggest card size in the set.
  • Hand and deck backs are 145px too.

Effect language

72px damage on the card; the target bracket stays outside the overlap. The tucked card remains a physical object, not a stamp.

Tradeoff

The spell/trap card is not fully visible at rest. Tap it to lift it forward; that is the physical cost of 145px cards.

04 / DECISION

Pick a card budget. Keep the card.

All four obey the same rule. Choose the trade you want: every card fully visible (Grid), the biggest card (Overlap), full rows with a side hand (Shelf), or all 12 board cards in a mirror arrangement (Mirror).

Overlap is the pick. 900 × 900, every card 145px, and the spell/trap card tucked 50px behind its monster. It is the largest card budget that still fits a full hand and all three lanes.

Ported to the real Table: the drawer has COMPACT 960 for the corner window and PIN for always-on-top. The board uses the same 145px token everywhere; the shipping set-card cut is the 44px Index Tab.
