Same two cards. Four peeks.

03 / THE FIX

Spread the stack only while looking.

The best improvement is not a different card size. It is a temporary separation: the monster moves down 30px and the set card keeps its 50px peek. The board breathes for exactly as long as the player is reading.

REST → SPREAD

One gesture, no layout change.

At rest the lane is the shipping Top Peek. Toggle the spread to see the same two 145px cards with the monster dropped 30px. The set card keeps its size, its position, and its ownership; the player gets the name, type, and first rules line back.

In the game this is the hover/press state, or the selected-hand state. The card never becomes a second size; the lane just opens.

REST / SPREAD · 145px
04 / UPGRADES

Six things that make any overlap playable.

These are independent of which peek you choose. Most of them are small presentation changes; none changes the 145px token or the rules.

01 / DEPTH

Make a pocket, not a stack

A recessed slot, a top shadow, and a 1px lit lip tell the eye the card is inside the mat. Without it, the set card reads as a rendering mistake. This is the single highest-value visual fix.

02 / HIT TARGET

Add a side tab

The top band is only 33–50px tall. A 10–12px side tab with a type diamond gives the set card a second click target and a visible edge without changing its size. It also makes the overlap feel intentional.

03 / MINIMUM

Never go below a 28px peek

At 10px the nameplate becomes a sliver. Either keep 28–32px for the name band, or fall back to the 120px token on short windows. The current stage already falls back at 1280 × 720; make the peek floor explicit.

04 / MOTION

Animate the tuck and the break

When a card is set, slide it up behind the monster. When the monster leaves, slide the set card forward into the empty lane. When the set card dies, slide it out from behind. The overlap becomes readable because the player saw it happen.

05 / HAND

Fan the hand, don't flatten it

Six 145px cards overlap by about 26px. Keep the token, add a slight fan and a hover lift, and the names stay readable. The hand becomes a hand, not a compressed row.

06 / DRAWER

Don't let the drawer eat the board

At 960 × 960 the 336px drawer covers a third of the lanes. A 280px drawer, a bottom sheet, or auto-close on board click keeps the overlap visible while the detail is open.

05 / DECISION

Keep Index Tab. Lift the card.

The live table now uses the **44px Index Tab**. It preserves the monster's full face, gives the set card a visible edge and a real hit target, and the hover lift shows the whole card without changing its size. The fixes are not a new overlap; they are depth, a side tab, a minimum peek, and a spread on hover/selection.

CHOSEN CUT

Index Tab 44 + hover lift.

The live table uses the 44px side tab. It keeps the monster's full face, gives the set card a visible edge and a real hit target, and the hover lift shows the full 145px card forward. The pocket and drawer ideas stay as future upgrades, not a second card size.

  • Done: 44px tab + hover lift + tab ghost/legal target.
  • Do next: tab-to-drawer slide on selection if you want both cards visible.
  • Do with the director: tuck-in, slide-forward on break, slide-out on destroy.
  • Do not: shrink the set card, hide the monster's name, or add a second token.
